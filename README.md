Структура проекта
- stack_struct.h - структура стека 
- dynamic_array_stack.h/.c - реализация стека на динамическом массиве
- linked_list_stack.h/.c - реализация стека на односвязном списке
- test_runner.c - программа для запуска тестов
- plot_results.py - скрипт для построения графиков
- run_tests.sh - скрипт для компиляции и запуска


Запуск

chmod +x run_tests.sh

./run_tests.sh
